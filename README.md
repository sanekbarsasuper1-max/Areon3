# Areon — звуковые файлы

Ни один аудиофайл сюда не включён — только структура папок и точное
описание, что должно лежать в каждой. AudioManager устроен так, что
отсутствие файла не ломает сайт (просто тишина + предупреждение в
консоли браузера), поэтому можно добавлять файлы постепенно, по одному.

## Где брать (проверено, конкретные страницы, не просто названия сайтов)

Всё ниже — CC0 (авторство указывать не обязательно, но приятно, если
не сложно) или явно бесплатно для коммерческого использования.

**Звуковые эффекты (почти всё, что нужно, в двух паках):**
- https://kenney.nl/assets/interface-sounds — 100 UI-звуков одним архивом.
  Хорошая база под `ui_confirm.mp3`, `ui_error.mp3`, `step_transition.mp3`.
- https://kenney.nl/assets/impact-sounds — 130 звуков удара/импакта.
  Подходит под `ban.mp3` (глухой удар = "запрет") и как основа для
  `pick_self.mp3`/`pick_enemy.mp3` (взять два разных по тембру звука
  из пака).
- https://kenney.nl/assets/ui-audio — ещё 50 UI-звуков, если в первых
  двух паках не найдётся подходящего варианта под `confirm`/`error`.

**Музыка для Draft Trainer (напряжённая, тёмная атмосфера):**
- https://opengameart.org/content/cc0-dark-music — курируемая подборка
  именно "тёмной, напряжённой" CC0-музыки, то, что нужно для
  `music/draft/theme.mp3`.
- https://opengameart.org/content/dark-ambience-loop — конкретный
  зацикленный трек, тёмный эмбиент, тоже хороший кандидат.

**Музыка для статистики (спокойная, технологичная):**
- https://opengameart.org/content/calm-ambient-1-synthwave-4k — синтвейв,
  спокойные пэды, ощущение "технологично и расслабленно".
- https://opengameart.org/content/calm-ambient-2-synthwave-15k — того же
  автора, чуть другой вариант того же настроения.
- https://opengameart.org/content/cc0-calm-relaxing-music — подборка,
  если первые два трека не подойдут по длине/структуре.

**Музыка для главной/турниров** — здесь готовой подборки под ровно
"современный киберспорт" не нашлось одним куском, поэтому лучше
смотреть живьём с фильтром по настроению:
- https://pixabay.com/music/search/genre/electronic/ — фильтр по
  жанру, включает энергичные электронные треки под "соревновательно"
  (`tournaments/theme.mp3`) и более сдержанные под "современно и
  технологично" (`home/theme.mp3`). Лицензия Pixabay не требует
  указания авторства.

## Где брать (общие каталоги, на случай если выше не подошло)

Дальше — точный список, что положить куда.

## Музыка (зацикленная, `loop: true` в коде)

Формат: MP3, 128-192kbps достаточно (это фон, не хайфай). Каждый трек
должен **бесшовно зацикливаться** (без щелчка на стыке конца/начала) —
это единственное жёсткое техническое требование, иначе будет слышен
"скачок" каждые несколько минут.

| Путь | Стиль |
|---|---|
| `music/home/intro.mp3` | ✅ добавлен. Играет **один раз**, при первом входе за сессию (и заново при повторном логине без перезагрузки страницы) — громче обычной фоновой музыки, затем плавно передаёт эстафету `music/home/theme.mp3`. Не зацикливается. |
| `music/home/theme.mp3` | Основная тема — современный киберспорт, технологично, слегка тёмная/мистическая атмосфера. Ненавязчивый фон для профиля/команд/поиска игроков. |
| `music/draft/theme.mp3` | Напряжённая, атмосферная — ощущение настоящего капитанского драфта: ожидание, важность решения. Не должна перекрывать восприятие таймера/звуков действий. |
| `music/statistics/theme.mp3` | Спокойная, технологичная — аналитика, данные, профессиональный киберспорт. Заметно спокойнее, чем draft/theme. |
| `music/tournaments/theme.mp3` | Соревновательная, чуть более энергичная, чем home/theme — ощущение турнирной сцены. |

## Звуковые эффекты (одноразовые, короткие)

Формат: MP3 или WAV, **0.1–1.5 секунды** для большинства (кроме
таймера — см. ниже). Премиальные, не похожие на дешёвые мобильные
уведомления — короткие, с характером, не пронзительные.

### Draft Trainer (`sfx/draft/`)

| Файл | Когда играет | Характер |
|---|---|---|
| `ban.mp3` | Любой бан (свой или чужой) | Ощущение удаления/запрета — глухой, отрывистый | ✅ добавлен |
| `pick_self.mp3` | Вы выбрали героя | Мощный звук подтверждения — важное решение |
| `pick_enemy.mp3` | Соперник/бот выбрал героя | Похож на pick_self, но заметно отличается (другой тон/тембр) |
| `phase_ban_start.mp3` | Начинается новая фаза банов | Отдельный переходный сигнал |
| `phase_pick_start.mp3` | Начинается новая фаза пиков | Отдельный переходный сигнал, отличается от phase_ban_start |
| `step_transition.mp3` | Любой переход к следующему шагу | Лёгкий, ненавязчивый — играет на КАЖДОМ шаге, должен быть тише остальных |
| `draft_complete.mp3` | Драфт завершён | Финальный, торжественный/весомый звук |
| `timer_tension.mp3` | Таймер пересёк отметку 10 секунд (играет один раз) | Нарастающее напряжение, не резкое |
| `timer_critical.mp3` | Каждую секунду, пока ≤5 секунд осталось | Короткий сигнал — играет до 5 раз подряд, не должен раздражать при повторении |
| `timer_expired.mp3` | Время вышло (бан пропущен / случайный пик) | Предупреждающий, отличается от timer_critical |

### UI (`sfx/ui/`)

| Файл | Когда | Характер |
|---|---|---|
| `confirm.mp3` | Подтверждение действия (например, отмена хода админом) | Короткий, нейтральный |
| `error.mp3` | Действие не удалось (занятый герой, не ваш ход и т.п.) | Короткий, но явно "отрицательный", не пугающий |

### Techies: Сапёр (`sfx/minigames/minesweeper/`)

| Файл | Когда | Характер |
|---|---|---|
| `reveal.mp3` | Открытие безопасной клетки | Короткий, механический — как щелчок детонатора без взрыва |
| `flag_place.mp3` | Установка флажка | Короткий, металлический |
| `flag_remove.mp3` | Снятие флажка | Похож на `flag_place`, но заметно отличается |
| `explosion.mp3` | Открыта мина | Настоящий взрыв — самый громкий и весомый звук во всей игре |
| `victory.mp3` | Поле полностью обезврежено | Триумфальный, но не длинный |
| `defeat.mp3` | Поражение (играет через ~0.4с после `explosion.mp3`) | Мрачный, короткий |

### Wheel of Fate (`sfx/minigames/wheel-of-fate/`)

| Файл | Когда | Характер |
|---|---|---|
| `spin_start.mp3` | Нажата кнопка SPIN THE WHEEL | Нарастающий, механический — как раскрутка |
| `result.mp3` | Колесо остановилось, показан результат | Весомый, "судьбоносный" — не просто уведомление |

### Системные переходы (`sfx/system/`)

| Файл | Когда |
|---|---|
| `nav_draft_open.mp3` | Открыт экран конкретной драфт-сессии |
| `nav_match_start.mp3` | Открыт разбор конкретного матча |
| `nav_statistics_open.mp3` | Открыт список матчей ("Статистика") |
| `nav_tournament_open.mp3` | Открыт список турниров |
| `nav_result.mp3` | Зарезервировано на будущее — пока нигде не вызывается из кода (см. "Честно про пробелы" ниже) |

## Честно про пробелы

- Полностью прописаны и вызываются из кода: все звуки Draft Trainer
  (`sfx/draft/*`), `ui_confirm`/`ui_error` (частично — только на
  паре конкретных точек, не на каждой ошибке во всём приложении),
  `nav_statistics_open` и `nav_tournament_open`.
- **Зарегистрированы в манифесте, но нигде ещё не вызываются**:
  `nav_match_start`, `nav_result`. Это не баг — просто не было
  очевидной единственной точки в коде, куда их врезать без
  дублирования логики, и это не входило в первый проход. Добавить
  вызов `playSFX('nav_match_start')` в `MatchAnalyzer.tsx` при
  монтировании — тривиально, если понадобится.
- Профиль, Команды, Поиск игроков, Админ-панель — используют музыку
  раздела `home` (по маппингу маршрутов в `App.tsx`), но не имеют
  собственных SFX-триггеров сверх общих UI-звуков.
